Order 1042
won’t ship.

A customer writes in: the order has been stuck in “pending” for two days. First stop is the data.

2 / 4

One field
is empty.

The order has no warehouse. A join confirms it: warehouse_id is NULL, so nothing knows where to ship from.

3 / 4

The API
says the same.

Replaying the dispatch call in a sandbox returns a 400. Two sources, one cause: a missing warehouse mapping.

4 / 4

Fix it,
then prove it.

Every other Lumen order ships from Tallinn, warehouse 7. So I set that on 1042 through the API (not by editing the database) and send the dispatch again.
